# Consigna

Registro compartido para inventario en consignación entre un emprendimiento y sus vendedores.

## El problema

Cuando un negocio reparte producto entre varios vendedores para que lo vendan por su cuenta, nadie tiene cómo comprobar con certeza cuánto le entregaron a cada uno, cuánto vendió, cuánto devolvió, y cuánto le corresponde cobrar o pagar. Hoy esto se lleva en Excel, WhatsApp o una base de datos que administra una sola persona, lo que deja la puerta abierta a errores y a que un registro se modifique sin que los demás lo sepan.

## La propuesta

Cada evento del ciclo (entrega, venta, devolución, liquidación) necesita la confirmación de ambas partes involucradas para quedar sellado. Una vez confirmado, ni el vendedor ni quien administra el sistema pueden alterarlo después. La liquidación deja de ser una negociación basada en la palabra de cada quien y pasa a ser un cálculo directo sobre hechos ya confirmados por los dos lados.

## Caso de validación

Vibra Luz, un emprendimiento familiar de venta de velas por distribución.
