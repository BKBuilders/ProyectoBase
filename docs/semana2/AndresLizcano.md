## Soy un comprador y quiero poder tener un registro claro y comprobable para poder tener cuentas claras y reputación.
## HU-01: Consultar y verificar el historial de compras
 
>> Como comprador, quiero consultar un registro claro y comprobable de mis compras, para mantener mis cuentas organizadas y construir una reputación basada en mis transacciones.
Criterios de aceptación
- El comprador puede consultar el historial de sus compras.
- Cada compra muestra producto, cantidad, fecha, vendedor y valor de la transacción.
- Cada transacción tiene un identificador único.
- El historial no puede ser modificado una vez confirmado.
- El comprador puede verificar que la información corresponde al registro almacenado en el sistema.



## Soy un vendedor y quiero poder tener un registro en conjunto con mis clientes para fidelizarlos.
## HU-02: Registrar y consultar el historial de clientes<
 
> Como vendedor, quiero mantener un registro compartido de las transacciones realizadas con mis clientes, para conocer su historial de compras y fortalecer la relación con ellos.
Criterios de aceptación
- El vendedor puede consultar el historial de transacciones de cada cliente.
- Cada registro muestra producto, cantidad, fecha y valor de la compra.
- El historial identifica al vendedor y al cliente involucrados.
- Las transacciones confirmadas no pueden modificarse ni eliminarse.
- El vendedor puede consultar la frecuencia y cantidad de compras realizadas por un cliente.


## Soy una empresa y necesito conocer qué tantos productos se devuelven de un proveedor para ver qué tan confiable es.
## HU-03: Consultar el historial de devoluciones de un proveedor
 
> Como empresa, quiero consultar la cantidad y el historial de productos devueltos a cada proveedor, para evaluar su confiabilidad y calidad de suministro.
Criterios de aceptación
- La empresa puede consultar las devoluciones asociadas a un proveedor.
- Cada devolución registra producto, cantidad, fecha y motivo.
- El sistema permite identificar el proveedor relacionado con cada devolución.
- La empresa puede consultar la cantidad total de productos devueltos en un período determinado.
- La información presentada corresponde a los movimientos registrados y confirmados en el sistema.



## Soy un cliente y quiero saber de dónde vienen los productos que compro para conocer en qué medios se producen y si son seguros para mi consumo.
## HU-04: Consultar la trazabilidad y procedencia de un producto
 
> Como cliente, quiero consultar la procedencia y trazabilidad de los productos que compro, para conocer su origen, proceso de producción y verificar que sean seguros para mi consumo.
Criterios de aceptación
- El cliente puede consultar el origen del producto.
- El sistema muestra información sobre el productor o proveedor relacionado.
- El cliente puede consultar los movimientos registrados del producto desde su origen hasta la venta.
- La información de trazabilidad no puede ser modificada una vez confirmada.
- El cliente puede verificar la información registrada para comprobar su autenticidad.


## Soy dueño de un negocio y quiero conocer el seguimiento, rendimiento y ganancias de mi empresa para conocer de forma clara qué funciona y qué puede mejorar.
## HU-05: Consultar el rendimiento y resultados del negocio
 
> Como dueño de un negocio, quiero consultar el seguimiento de las ventas, inventario y ganancias de mi empresa, para identificar qué está funcionando y qué aspectos pueden mejorar.
Criterios de aceptación
- El dueño puede consultar las ventas realizadas en un período determinado.
- El sistema muestra información sobre ingresos, productos vendidos e inventario.
- El sistema permite consultar las ganancias generadas.
- El dueño puede comparar los resultados de diferentes períodos.
- La información presentada se genera a partir de las transacciones registradas en el sistema.

Historia más importante y justificación
La historia más importante es HU-04: Consultar la trazabilidad y procedencia de un producto, porque permite al cliente conocer el origen y recorrido del producto que está adquiriendo, aportando transparencia y confianza en la transacción. Además, esta historia aprovecha uno de los principales beneficios del sistema: mantener un registro verificable de los movimientos realizados sobre los productos. Sin esta información, el cliente no tendría una forma clara de comprobar de dónde proviene el producto ni de consultar su recorrido dentro de la cadena de suministro.
